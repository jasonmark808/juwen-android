# 聚闻安装与部署说明

## 1. 安装 APK

1. 将 `juwen-redmi-pad-pro.apk` 传到红米 Pad Pro。
2. 在平板设置中允许文件管理器“安装未知应用”。
3. 点击 APK 安装。该文件使用项目调试证书签名，适合个人使用。
4. 首次启动时允许通知权限。

## 2. 建立免费新闻数据源

1. 在 GitHub 新建一个公开仓库。
2. 将本项目源码推送到仓库的 `main` 或 `master` 分支。
3. 打开仓库 `Settings -> Pages`，Source 选择 `GitHub Actions`。
4. 打开 `Actions`，手动运行一次 `Publish news feed`。
5. 工作流完成后，数据地址通常是：

   `https://<你的GitHub用户名>.github.io/<仓库名>/feeds/latest.json`

6. 在聚闻 App 的“设置”中填入该地址并保存，然后回到“今日”点击刷新。

默认工作流每两小时运行一次。它使用规则完成聚合、分类、去重和重要性判断，不需要任何 AI Key。

## 3. 国内网络优化

- App 会保留最后一次成功数据，断网时仍可阅读。
- 如果 GitHub Pages 访问不稳定，可在 App 设置中改成自己的 CDN 镜像地址。
- `NEWSNOW_API_BASE` 可在 GitHub 仓库的 `Settings -> Secrets and variables -> Actions -> Variables` 中配置，指向自选的 NewsNow 兼容接口。
- 不要把 API Key、Webhook 或私人信息写进仓库文件。

## 4. HyperOS 设置

为了提高后台同步成功率：

1. 在“设置 -> 应用设置 -> 应用管理 -> 聚闻”中允许自启动。
2. 将省电策略设置为“不限制”。
3. 允许通知，并按需关闭锁屏通知内容预览。

Android WorkManager 和 GitHub Actions 都是尽力调度，重大新闻提醒可能有 1 至 3 小时延迟，不应视为严格实时服务。

## 5. 可选 AI

当前交付默认完全关闭 AI。后续若启用，只应在 GitHub Secrets 中保存兼容 OpenAI 接口的地址和密钥。AI 失败不能阻止基础新闻流生成。

## 6. 构建源码

建议使用 Android Studio 自带 JDK 17 或 21、Android SDK 35 和 Gradle 8.10.2：

```powershell
./gradlew testDebugUnitTest lintDebug assembleDebug
```

GitHub 的 `Build Android APK` 工作流也会构建并上传 APK Artifact。
